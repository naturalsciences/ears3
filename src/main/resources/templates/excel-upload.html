    • Open it with Excel/LibreOffice and save it as an xlsx file.
    • Make sure the worksheet is named 'events'.
    • Now repeat the events as much as needed over the whole cruise.
    • Do not complete (or just remove) the following columns, as the info is not essential for a full event (it's built from what you provide):
      • Program name
      • Principal Investigator
      • Tool category
      • Tool category code
      • Tool code
      • Acquisition Timestamp
      • and all subsequent acquisition info (EARS gets this for you!)
    • At the end of the cruise, upload this excel file via the above form.
