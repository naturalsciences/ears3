  • Since the tool/process/action names must exactly correspond and their combinations as well, we strongly advise you to do as follows:

    • Open the csv file with Excel/LibreOffice and save it as an xlsx file.

    • Now repeat the events as much as needed over the whole cruise. Keep the file under 5MB.

      • Principal Investigator
      • Tool category
      • Tool category code
      • Tool code
      • Acquisition Timestamp
      • and all subsequent acquisition info (EARS gets this for you!)
    • At the end of the cruise, upload this excel file via the above form.
